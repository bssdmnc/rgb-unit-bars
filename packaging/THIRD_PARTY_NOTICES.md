# Third-party components

## OpenRGB 1.0

RGBUnitBars.exe bundles an unmodified copy of OpenRGB 1.0 (Windows 64-bit, build 81bbe18), which it starts in the background as a local SDK server when no OpenRGB server is already running.

* Project: https://openrgb.org
* License: GNU General Public License v2.0
* Source code: https://codeberg.org/OpenRGB/OpenRGB/src/tag/release_1.0

## Python libraries

hidapi (BSD / GPL-3 / original HIDAPI licence), mss (MIT), openrgb-python (GPL-3.0), pystray (LGPL-3.0), Pillow (MIT-CMU), bundled with the Python runtime (PSF License) by PyInstaller (GPL-2.0 with bootloader exception).
